# AIキーパー・ワークスペース運用手順

TRPG未経験でも、この順に進めれば回せます。相手はClaude Code／Codex等のエージェントです。

## 0. 構成（このディレクトリ）

- `keeper_prompt.md`：エージェントへの最初の指示。毎回これを読ませる。
- `scenario/`：不変の真相・NPC・情報表。エージェントも人間も書き換えない。
- `state/`：確定事項・PC状態。毎手番エージェントが更新する。
- `log/`：プレイ記録。追記専用。消さない。

## 1. 始め方

1. エージェントをこのディレクトリで起動する。
2. 最初にこう送る：「`keeper_prompt.md` を読んで、DLとしてセッションを開始してください」
3. あとはPLとして発言するだけ（「PL1：〜します」）。

## 2. 中断と再開

- 中断するとき：「ここまでを `state/` に保存して」
- 再開するとき：同じディレクトリでエージェントを起動し、「`keeper_prompt.md` と `state/` を読んで再開してください」

## 3. 長期化して重くなったら

- 「`log/` を要約して `state/` に畳んで」と送る（圧縮）。
- 要約後は古いログを消さず残す。確定事項だけが `state/` にあればよい。

## 4. GUI（ブラウザのチャット）で回す場合

- 同じ `keeper_prompt.md`＋シナリオ文書を貼る。
- 30分ごとに「ここまでの確定事項を箇条書きして」と送り、出た要約を手元に残す。
- ファイル更新の代わりは人間がコピー＆ペーストする。
