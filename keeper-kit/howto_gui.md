# ブラウザのチャットで回す手順

1. `keeper_prompt_template.md` の［ ］を埋める（対応シナリオなら `keeper_notes.md` の転記文を貼る）。
2. プロンプト→シナリオ本文→HOの順で貼る。長い文書は概要→真相→シーンに分ける。
3. ルールは公式ルールブックを別タブで開く。全文貼り付けは不要。
4. PLは名前と職業を告げる。以降は「PL1：〜します」と発言するだけ。
5. 判定を求められたらダイスを振り、出目を報告する（手元のサイコロ可、AI代行可）。
6. 30分ごとに「ここまでの確定事項を箇条書きして」と送り、要約を手元に残す。
7. 終幕後、`eval_sheet.md` に記録する。
