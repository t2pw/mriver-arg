# 公開手順 v1（2026-06-11）

「声は壁を透して」を無料ホスティングで一般公開するための手順とチェックリスト。

## 0. 前提と考え方

- **この GitHub リポジトリは公開＝ docs／scenario_text.txt／引き継ぎメモなどの完全なネタバレが誰でも読める。**
  プレイヤーに案内するURLは、**ゲームファイルだけを置いた別ホスティング**にする。
  （リポジトリのURLは作品ページ等に書かない。逆に、解かれてもよい「制作の裏側」として
  いずれ公開するのも選択肢——その判断は公開後でよい）
- ゲームは完全な静的サイト。ビルド不要・サーバ処理なし。外部依存は
  Google Fonts と cdnjs（Leaflet）の2つのCDNのみ。

## 1. 配布物の生成

```powershell
node build_dist.js
```

`dist/` に必要ファイルのみが入る（index.html / phone_shell.html / os.js / CREDITS.md /
pages/ / tools/ / images/）。開発資料の混入は スクリプトが自動検査する。
`dist/` は .gitignore 済み（コミットしない）。

## 2. ホスティング（無料・いずれか）

| サービス | 手順 | 備考 |
|---|---|---|
| **Netlify Drop（推奨・最速）** | app.netlify.com/drop に `dist/` フォルダをドラッグ&ドロップ | 無料アカウント要。即URL発行（`○○.netlify.app`）。サイト名は設定で変更可。更新も同じ画面に再ドロップ |
| **Cloudflare Pages** | ダッシュボード → Pages → 「アップロード」で `dist/` を直接アップロード（Git連携は使わない） | `○○.pages.dev`。無料枠が広い。**Git連携にするとリポジトリ全体（docs含む）を見られる経路が増えるので直接アップロード方式にすること** |
| **itch.io** | `dist/` を zip にして「HTML プロジェクト」としてアップロード | ゲームとしての発見性が高い。iframe 内動作のため localStorage・表示崩れの実機確認を先に行うこと（未検証） |

## 3. 公開直前チェックリスト

- [ ] `node extract_scenario.js` → `node check_progression.js` が全項目グリーン
- [ ] `node build_dist.js` 成功（開発資料の混入検査が通る）
- [ ] dist をローカルで一度開いて動作確認（`cd dist; python -m http.server` 等。file:// 直開きは fetch 制約で挙動が変わる場合がある）
- [ ] **デバッグパネルが見えないこと**（`?dev` なしの通常URLで履歴アプリの DEV ボタンが出ない）
- [ ] localStorage を全消去した状態（シークレットウィンドウ）で最初から動くこと
- [ ] X シェア（追記END／okaeri）が正しいURLで開くこと（シェアURLは location.href から自動取得＝ホスト非依存）
- [ ] スマホ実機で表示確認（390px想定）

## 4. URL確定後にやること

1. **og:image の追記**（index.html）：
   ```html
   <meta property="og:image" content="https://＜公開URL＞/images/photo_takkope.jpg">
   ```
   追記したら再ビルド→再アップロード。
2. X で自分のシェアボタンを一度押し、カードの見え方を確認（Card Validator は廃止済み。実投稿のプレビューで確認）。
3. 制作者テスト用URL：`https://＜公開URL＞/phone_shell.html?dev` でデバッグパネルが使える。
   **このURLは公開しないこと。**

## 5. 運用メモ

- 更新フロー：リポジトリで編集 → 検証 → `node build_dist.js` → ホスティングに再アップロード。
  GitHub へのプッシュとプレイヤー向け公開は**連動しない**（安全側）。
- GitHub Pages（リポジトリ直serve）を有効にしている場合、そちらは docs ごと配信される。
  プレイヤー向けに案内しないこと。不要なら Settings → Pages で無効化してよい。
- 素材出典は CREDITS.md（dist 同梱）と photo_002 のゲーム内クレジットで担保。
- 免責表示：index.html の meta／フッタ、archive_about 末尾の免責ブロックで担保済み。
