# 公開手順 v2（2026-06-12 改訂）

「声は壁を透して」の公開・更新運用。v1（手動アップロード方式）から
**prod ブランチ＋ Cloudflare Git 連携の自動デプロイ**に移行した。

## 0. 前提と考え方

- **この GitHub リポジトリは公開＝ docs／scenario_text.txt／引き継ぎメモなどの完全なネタバレが誰でも読める。**
  プレイヤーに案内するのは Cloudflare の公開URLのみ。リポジトリのURLは作品ページ等に書かない。
- Git 連携でも、**ビルド出力ディレクトリを `dist` に指定すれば配信されるのは dist の中身だけ**。
  docs はリポジトリにあっても配信されない（`build_dist.js` が混入を自動検査する）。
- ゲームは完全な静的サイト。外部依存は Google Fonts と cdnjs（Leaflet・SRI付き）の2つのCDNのみ。

## 1. ブランチ運用

| ブランチ | 役割 |
|---|---|
| `main` | 開発。日常のコミットはすべてここ |
| `prod` | **本番**。Cloudflare が監視し、push されると自動ビルド・デプロイ |

リリース手順（main の内容を本番に反映する）：

```powershell
node extract_scenario.js
node check_progression.js   # 全項目グリーンを確認
node build_dist.js          # ローカルでビルドが通ることを確認
git push origin main:prod   # ← これだけで本番反映
```

main へのプッシュでは公開は更新されない（安全側）。

## 2. Cloudflare 側の設定（初回のみ）

ダッシュボード → Workers & Pages → 対象プロジェクト → ビルド設定。
**プロジェクトの種類によって設定項目が違う**ので注意：

### A. Pages の場合（**現行**。2026-06-12 移行。URL：mriver-arg.pages.dev）

- **接続リポジトリ**：t2pw/mriver-arg
- **本番ブランチ（Production branch）**：`prod`
- **ビルドコマンド**：`node build_dist.js`
- **ビルド出力ディレクトリ**：`dist`
- フレームワークプリセット：None

### B. Workers の場合（旧方式・廃止済み）

旧 Worker（mriver＝workers.dev）は 2026-06-12 に削除済み。wrangler.jsonc も撤去した。
もし将来 Workers でホストし直す場合は、`wrangler.jsonc`（name／compatibility_date／
`assets.directory: "./dist"`）をリポジトリ直下に置き、ビルドコマンド `node build_dist.js`＋
デプロイコマンド `npx wrangler deploy` を設定する。

### プレビューデプロイの無効化（Pages・推奨）

main への push でプレビューURLが生成されるのを止める：
ダッシュボード → Workers & Pages → mriver-arg → **Settings → Builds & deployments**
（日本語UIでは「ビルドとデプロイ」）→ **Branch control／プレビューブランチ** の項目で
プレビューブランチを **None（なし）** にして保存。
（UI改版で「Configure Preview deployments」というボタン名の場合もある。
要は「Production branch: prod ／ Preview branch: None」になっていればよい）

※ どちらの場合も、プレビューデプロイ（main 等への push で生成されるプレビューURL）が
不要なら無効にしておく（プレビューURLからの漏れ防止）。
※ リポジトリに dist/ は入っていない（.gitignore 済み）が、**それは正常**。
ビルドコマンドが Cloudflare 上で dist/ を生成する。

## 5. 運用メモ

- GitHub Pages（リポジトリ直serve）を有効にしている場合、そちらは docs ごと配信される。
  プレイヤー向けに案内しないこと。不要なら Settings → Pages で無効化してよい。
- 素材出典は CREDITS.md（dist 同梱）と photo_002 のゲーム内クレジットで担保。
- 免責表示：index.html の meta／フッタ、archive_about 末尾の免責ブロックで担保済み。
- 旧方式（dist/ の手動アップロード：Netlify Drop／Cloudflare直接アップロード／itch.io zip）も
  引き続き可能。itch.io は iframe 内動作（localStorage・表示）の実機検証を先に行うこと。
