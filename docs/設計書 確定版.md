## コアコンセプト

**「記録されなかった手紙を、あなたが記録する」**

M川事件（松川事件をモチーフとした架空の事件）という歴史を、蛸川小蘭という架空の人物の目を通して追体験する。14年間の市民運動が冤罪を覆した事実を知り、最後に「記録されなかった一通」をプレイヤー自身が架空の文集に追加する。

---

## 架空文集の設定

**「声は壁を透して ── M川事件の被告と家族の手紙」**

- 実在の文集「愛情は壁を透して」（1954年・青木書店）をモチーフとした架空の文集
- 発行：M川事件被告を守る会　昭和二十九年（1954年）
- 収録：被告・家族・支援者からの手紙　約三百通
- **未収録：猫塚ふみからの手紙一通**
  - 理由：宛先が「猫塚清治」のため、記録上存在しない人物への手紙として収録できなかった

## 登場人物

### 蛸川小蘭（たこがわ こらん）
- 現代の芙島市在住のITエンジニア。30代女性
- M川事件の調査中に「声は壁を透して」に収録されなかった手紙の存在を知る
- その手紙を探すうちに1949年に引き寄せられた（理由は永遠に不明）
- タコのぬいぐるみを持っていた
- **追加設定：M川事件の現場付近にいた「身元不明の不審人物」として当局にマークされた**
  - 戸籍なし・住所なし・現代語を使う説明不能な存在
  - 事件関与者または「都合の悪い目撃者」と見なされた
  - 月湯温泉で偽名「蛸川」を名乗り24年間潜伏

### 猫塚清治（ねこづか せいじ）
- K鉄の保線作業員。34歳
- M川事件の夜、現場付近にいたが被告リストにも証人リストにも名前がない
- 記録から消えた人物
- 妻ふみと芙島市郊外で暮らしていた

### 猫塚ふみ（ねこづか ふみ）
- 清治の妻
- **誕生日は三月十四日（＝№0314の由来）**
- 夫が記録から消えた後も14年間、芙島市で暮らし続けた
- 「声は壁を透して」に収録されなかった手紙の差出人
- 宛先が「猫塚清治」だったため、記録上存在しない人物への手紙として文集に収録できなかった

## 潜伏・暗号化の理由（確定版）

| 行動 | 理由 |
|---|---|
| 月湯温泉に24年潜伏 | 当局に追われ、戸籍のない「不審人物」として逃げ続けた |
| 「蛸川」という偽名 | 本名がないため、その場でとっさに名乗った |
| バイナリ・暗号で記録 | 当局に押収されても読めない形式にする必要があった |
| 記録を5か所に分散 | 一か所が押収されても全体が失われないように |
| 投書が掲載されなかった | 掲載前に当局の検閲で差し止められた |
| 蒼沼ブルーランドを最終保管場所に | 廃墟になるまで待ち、当局の目が届かなくなってから隠した |

- 正解語句を入力すると該当ページが「復元済み」として解放される

- ガード機能：discovery.jsが未解放ページへの直接アクセスをブロック
