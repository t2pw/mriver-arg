シナリオ開発指示書：『声は壁を透して』ブラッシュアップ計画
1. プロジェクト概要
本作は、1949年の国鉄三大ミステリー（松川事件をモデルとした「M川事件」）と、2026年のプレイヤーを繋ぐ、時間遡行・因果のループをテーマにしたARG（代替現実ゲーム）である。
未来のITエンジニア「蛸川小蘭」（旧設定の「ふみ」の役割を統合）が1949年に逆行し、14年間潜伏して残した「遅い記録」を、現代のプレイヤーが観測・確定させることで物語が完結する。

2. コア改修方針（Claude Codeへの指示用）
指針①：キャラクター設定の統合（小蘭 ＝ 旧・ふみ）
現状: テキスト内に「ふみ」の誕生日に言及するコードや名残が存在する。

改修指示: * 「ふみ」というキャラクターを独立させず、「蛸川小蘭が1949年〜1963年の潜伏期間中に、過去の世界で生き抜くために名乗っていた偽名（あるいは周囲からそう呼ばれていた愛称）」として再定義せよ。

これにより、14年間の生活感、孤独、そして猫塚清治との絆をすべて小蘭一人に集約させ、キャラクターの感情的強度を最大化すること。

指針②：1963年（昭和38年）における「記録媒体」のSF的リアリティ付与
現状: 1963年の過去に現代的な物理メモリ（マイクロSD等）を残したとする記述があり、技術的整合性に隙がある。

改修指示:

単に「未来の物理メモリ」をそのまま置くのではなく、「未来のエンジニアである小蘭が、1960年代当時の技術（磁気テープや真空管、あるいはタコのぬいぐるみの内部に編み込んだ極細の超伝導フィラメントなど）と擦り合わせて、執念で偽装・製造した特殊な記録媒体」という描写に変更せよ。

「2026年の技術」と「1963年の技術」のミッシングリンク（摩擦）をSF的ギミックとして補強すること。

指針③：パズル要素（4桁の数字）の「現実の歴史・地理」への着地
現状: モールス信号や16進数から導き出される4桁の数字が、単なるパズル解法として完結している。

改修指示:

導き出される4桁の数字（例: 0816 など）に、単なる「キャラクターの記号」以上の意味を持たせること。

実際の松川事件の発生日時、裁判記録の特定の数字、あるいは福島県の実際の事件現場の座標（緯度・経度の一部）など、プレイヤーが現実のWebやGoogleマップで検索した際に「現実が侵食してくる恐怖と興奮」を覚えるようなリアルな歴史・地理データと連動した仕様にリファクタリングせよ。

指針④：歴史小説としての社会的力学（清治が消された理由）の肉付け
現状: 猫塚清治が公式記録から消された理由が「当局（警察・GHQ等）にとって都合の悪い目撃者だったから」という一面的描写に留まっている。

改修指示:

昭和24年特有のドロドロとした社会的力学を反映させること。

「当局から追われた」だけでなく、「左翼労働運動の身内（組合側）にとっても、彼が現場にいたことが戦術上・思想上で不都合だったため、左右両陣営の政治的思惑の狭間で、歴史の真空地帯に押し流されて消えた」という、時代の空気が持つ残酷さを手記（テキスト）に数行滑り込ませ、物語の深度を深めること。

指針⑤：象徴モチーフ（タコのぬいぐるみ）の文学的補強
現状: 「蛸川」という偽名の由来としてタコのぬいぐるみが登場している。

改修指示:

タコが持つ生物的特徴（「複数の脳を持ち独立して思考する」「環境に擬態する」「墨を吐いて姿をくらます」）を、歴史の闇に隠れて多層的なバグ（記録）を仕込む小蘭の行動原理のメタファー（象徴）として機能させる描写・テキストを補強せよ。

3. 実装上の注意（技術的・演出面の維持）
2000年代初頭のWeb演出の維持: { const v=document.getElementById... } などのレトロなスクリプト演出や、T.Watanabe's Tools Page のような黎明期インターネットのテキスト表現は、本作の「情報の重さの非対称性」を際立たせる優れた演出であるため、ロジック改修時にもこの空気感を破壊しないこと。

キャッチコピーの核: 「速くなかった。軽くなかった。だから残った。」 というテーマ軸からブレる描写は一切行わないこと。
