# TRPG初心者向け導入ガイド（AIキーパーで一人で遊ぶ）

TRPG未経験でも、この文書の順に進めれば一人でテストプレイできます。
使うのはあなたのPC1台だけです。相手はAIキーパーです。

## 0. 用語（5個だけ覚える）

- PL：プレイヤー。あなた。
- PC／共鳴者：あなたが操作する登場人物。
- DL／キーパー：物語を進める係。今回はAIが担当。
- HO（ハンドアウト）：あなたの役割が書かれた配布物。HO1だけ使う。
- 判定：うまくいくかダイスで決めること。AIの指示通りに振るだけ。

## 1. 用意するもの

1. Ollama（https://ollama.com）をインストールする。
2. 日本語の指示に従える8B級モデルを1つ入れる。目安コマンド：
   - `ollama pull qwen2.5:7b-instruct`（例。配布名は変わることがある）
   - VRAM 8GBに収まることの確認：`ollama ps` でメモリ使用を見る。
   - 応答が変なら、量子化の軽い版（Q4_K_M表記）に変える。
3. クラウド比較用（任意）：ふだん使う生成AIのチャット画面を用意する。

## 2. 回し方（60〜90分×2回想定）

1. `docs/ai_keeper_prompt_v1.md` の貼り付け文をAIに送る。
2. `docs/emoklore_scenario_koe_v1.md` を読ませる（長い場合は概要→真相→シーンの順に2〜3回に分ける）。
3. AIの案内で共鳴者（PC）を1人作る。名前・職業・共鳴感情3つを決めるだけ。
4. 導入から開始。「〜します」「〜を調べます」と送ると物語が進む。
5. 判定を求められたらダイスを振る（手元のサイコロでも、AIに「代わりに振って」と頼んでもよい。出目は正直に申告する）。
6. 詰まったら「ヒントをください」と送る。2段階まで出る。
7. 終幕の選択（追記する／しない）で終了。

## 3. 一人で遊ぶコツ

- HO2は使わない。HO1の一人旅として回す。
- 沈黙が怖くない。考える時間は自由に取ってよい。
- 変なことをしてもよい。AIキーパーが拾って返すのがTRPGの面白さ。
- 記録を取る：確定した情報だけメモ帳に残すと、後半が楽になる。

## 4. 評価の観点（テストの記録用）

回し終わったら、以下を5段階でメモする。

1. 調査の手応え（断片を集めて組み立てる楽しさはあったか）
2. 共鳴の実感（感情が物語に絡んだか）
3. 終幕の重さ（選択に悩めたか）
4. AIの破綻回数（真相漏れ・設定矛盾・進行停止の回数）
5. もう一度回したいか

4が多ければプロンプトかモデルを変える。1〜3が低ければシナリオ側を直す。
この切り分けがテストの目的である。

## 5. よくある詰まりと対処

- AIが真相を漏らした → その回は参考記録にし、プロンプトの禁止事項を強調して再開する。
- AIが進まない → 「選べる行動を3つ出して」と送る。
- 判定の数え方が分からない → 「出目は○○でした。成功数を数えて」と送る。
- 長くなってAIが忘れる → 「ここまでの確定事項を要約して」と送り、出た要約を貼り直す。
