## コンセプト

- ホーム画面の固定3アプリ（ブラウザ／メッセージ／履歴）に加え、
  **インストールした解析アプリ**が動的にアイコンとして並ぶ。
- 解析アプリは最初は存在しない。電文ページ等で「入手」して初めてホームに現れる。
- 解析アプリは「画像を見て人間が読み取った値」を手入力 → 変換結果を返す電卓的ツール。
- 手段ごとに別アプリ（16進変換器 / モールス読取機 / バイナリ復号機 …）。

## データモデル（os.js）

新規 localStorage キー：`koe_installed_apps`（インストール済みアプリIDの配列）。

```js
const INSTALLED_KEY = 'koe_installed_apps';

// 解析アプリ定義テーブル（os.jsに追加）
const TOOL_APPS = [
  {
    id: 'hexconv',
    name: '16進変換器',
    icon: '🔢',
    spoke: 'E',
    desc: '16進数をカタカナに変換する解析ツール。',
  },
  {
    id: 'morse',
    name: 'モールス読取機',
    icon: '📻',
    spoke: 'E',
    desc: '穿孔パターンをモールス符号として数字に変換する。',
  },
  // 今後：binary（C）、coord（D）など
];

const getInstalled = () => ls.getSet(INSTALLED_KEY);
const isInstalled  = id => getInstalled().has(id);
const installApp   = id => { const s=getInstalled(); if(s.has(id))return false; s.add(id); ls.saveSet(INSTALLED_KEY,s); return true; };
const getToolApp   = id => TOOL_APPS.find(a=>a.id===id);
```

`resetAll()` に `INSTALLED_KEY` を追加（リセットで初期化されるように）。

## ホーム画面の動的描画（phone_shell.html）

現状はアプリアイコンがHTMLにベタ書き。これを「固定3つ＋インストール済み」の動的生成に変更。

- 固定3アプリは現状維持。
- その下（または同じグリッド内）に、インストール済み解析アプリのアイコンを生成。
- 新規インストール直後は、アイコンに**ポップイン演出**（scale 0→1＋淡いフラッシュ）を付ける。

```js
function renderHomeApps() {
  const grid = document.getElementById('tool-grid'); // 解析アプリ用の新グリッド
  const installed = [...KoeOS.getInstalled()];
  grid.innerHTML = installed.map(id => {
    const a = KoeOS.getToolApp(id);
    if(!a) return '';
    return `<div class="aico" onclick="Shell.openTool('${a.id}')">
      <div class="aibox tool-icon" style="...">${a.icon}</div>
      <span class="ailabel">${a.name}</span>
    </div>`;
  }).join('');
}
```

HTML側：`#grid` の下に解析アプリ用の `#tool-grid` を追加（インストール0件なら非表示）。

## インストール演出フロー

電文ページ内の「入手」ボタン → `Shell.installTool('hexconv')` を呼ぶ。

```js
function installTool(id) {
  const app = KoeOS.getToolApp(id);
  if(!app || KoeOS.isInstalled(id)) return;
  // 1. インストール中モーダル（プログレスバー風）
  showInstallModal(app);          // 「ツールを取得しています…」プログレス2秒
  // 2. 完了後
  setTimeout(() => {
    KoeOS.installApp(id);
    closeInstallModal();
    // 3. ホームに戻してアイコンをポップイン
    Shell.goHome();
    renderHomeApps();
    flashNewIcon(id);             // 新アイコンを光らせる
    Shell.pushNotif(app.icon, 'アプリ', `${app.name} をインストールしました`, null);
  }, 2000);
}
```

モーダルは既存スプラッシュのCSSを流用できる（中央寄せ＋プログレス）。

## 解析アプリ画面（新規アプリ種別）

`Shell.openTool(id)` で、ブラウザ/メッセージ/履歴と並ぶ第4の画面種別として開く。
中身はアプリごとに `TOOL_UI[id]()` 関数で定義（pages/ と同様の動的ロード）。

### 16進変換器（hexconv）のUI

```
┌─────────────────────────┐
│  16進変換器              │
├─────────────────────────┤
│  16進値を入力（スペース区切り）│
│  ┌───────────────────┐  │
│  │ 53 55 4A          │  │ ← プレイヤーが画像を見て手入力
│  └───────────────────┘  │
│         [ 変換 ]         │
├─────────────────────────┤
│  結果：ショウジ          │ ← 変換ボタンで表示
├─────────────────────────┤
│  ── 変換対応表           │
│  ア=41 イ=42 ウ=55 ...   │ ← アプリ内に表を内蔵
└─────────────────────────┘
```

- 入力は自由テキスト（手入力）。読み取り＝人間、変換＝アプリ。
- 変換ロジック：内蔵の16進→カタカナ表で1値ずつ引いて連結。
- 表にない値は「?」を返す（誤読のフィードバック）。

### モールス読取機（morse）のUI

```
┌─────────────────────────┐
│  モールス読取機          │
├─────────────────────────┤
│  穴の並びを入力          │
│  ・=短  −=長（升ごとに改行 or スペース）│
│  ┌───────────────────┐  │
│  │ −−−−−             │  │ ← 第1升
│  │ ・・・−−           │  │ ← 第2升
│  │ ・−−−−             │  │
│  │ ・・・・−           │  │
│  └───────────────────┘  │
│         [ 変換 ]         │
├─────────────────────────┤
│  結果：0314              │
├─────────────────────────┤
│  ── モールス数字表       │
└─────────────────────────┘
```

- 入力は ・ と − の文字列。升ごとに区切り（改行 or スペース）。
- 変換ロジック：内蔵のモールス→数字表で升ごとに引いて連結。
- 入力記号は全角・半角ゆらぎを正規化（`.`→`・`、`-`→`−` など）。

## 電文ページ側の改修（telegram_001.js）

現状の「タップ補助ツール内蔵」を撤去し、以下に置き換え：

1. 生データ画像（`puzzle_e_hex.jpg` / `puzzle_e_shoji.jpg`）を表示。
2. 解析ツール未所持なら「このデータの解読には専用ツールが必要」＋入手ボタン2つ。
3. 所持済みなら「解析ツールで読み取ってください」＋ツールを開くショートカット。
4. 最終的に出た `0314` を、ブラウザ復元欄に入力させる（既存のキーワード解放フローに合流）。

→ 電文ページからツールが分離されることで「画像を読む→別アプリに転記→変換→復元欄」の手数が生まれ、中難度になる。

## 技術上の注意（引き継ぎメモより）

- innerHTML注入後の結線は `setTimeout(()=>{...},0)`。
- 新ページ/ツール追加時は os.js の定義テーブルと、phone_shell の動的ロード両方に登録。
- localStorageキーを新設したら必ず `resetAll()` に追加。
- ポップイン等のCSSアニメは既存 `@keyframes fadeUp` を流用 or 新規追加。
